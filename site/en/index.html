What NOVA can do

Ask for what you need in plain language: NOVA picks the right tool and does it for you, instead of explaining how to do it.

Your files

Read, search, sort, rename or summarise your documents. "Sort my downloads by type", "what does this PDF say?".

Commands, with your approval

For everything else, NOVA writes a PowerShell command and shows it to you. Nothing runs until you click "Allow".

The web and the weather

Web searches, reading pages, your local weather: NOVA fetches up-to-date information.

Documents

A CV, a letter, revision notes? NOVA creates real PDF, Word, HTML or CSV files, with a preview in the conversation.

Images and visuals

Illustrations, wallpapers, logos, diagrams or small interactive pages, right in the chat.

At home, not in the cloud

NOVA runs on your PC. Your conversations are saved on your computer, and NOVA has no server, no account and no usage tracking.

You stay in control

An assistant that acts on your computer has to be trustworthy. NOVA is built to never act behind your back.

It asks before acting

Running a command, deleting, moving or overwriting a file, opening a folder that isn't its own: NOVA always asks you first.

Protected against traps

A web page or a file can hide instructions aimed at the AI. NOVA spots them, warns you, and asks again before any action that follows.

Dangerous files flagged

Before opening a program, a script or a downloaded file, NOVA has Microsoft Defender scan it and warns you.

Open code

All of NOVA's code is public on GitHub: anyone can check what it does. Installers are built by GitHub from that code.

Installation

About ten minutes the first time.

Windows 10 or 11, 64-bitWith an Internet connection during installation.
A Claude Pro or Max planNOVA thinks with Claude, Anthropic's AI, through Claude Code. A free Claude account is not enough.

  1. Download NOVA

    Click here or on the "Download" button at the top of the page: NOVA-setup.exe downloads right away. If your browser says the file isn't commonly downloaded, choose "Keep".

  2. Run the installer

    Open the downloaded file. The installer isn't signed yet, so Windows shows "Windows protected your PC": click More info, then Run anyway.

    This is normal for new unsigned software. To check that your file is the original one, compare its SHA-256 fingerprint with the one on the release page (see the FAQ).

  3. Install Claude Code

    Open Windows PowerShell from the Start menu, paste this official Anthropic command and press Enter:

    irm https://claude.ai/install.ps1 | iex

    Close PowerShell, open it again, type claude and sign in with your Claude account on the page that opens.

  4. Open NOVA

    Start NOVA from the Start menu: it finds your Claude account and you're ready. Try "What's on my desktop?".

FAQ

Is NOVA really free?

Yes: NOVA is free and open source, under the MIT license. The AI that powers it comes from your own Claude plan (Pro or Max), paid directly to Anthropic. NOVA earns nothing from it.

Why does Windows say the app isn't recognised?

Because the installer isn't digitally signed yet, so Windows doesn't know the publisher. An application for free open source code signing has been sent to SignPath Foundation. Meanwhile, you can check that your file is the original: in PowerShell, run Get-FileHash .\NOVA-setup.exe in your Downloads folder and compare the result with the SHA-256 shown on the latest release page.

Installing Claude Code says "the remote name could not be resolved"

Your network probably blocks claude.ai, which is common on company or school networks. Try from another connection, such as your home Internet or your phone's hotspot.

Can NOVA mess up my PC?

Every action that changes your computer (command, deletion, move, overwriting a file) goes through a confirmation window that shows exactly what will happen. You can always refuse. Read these windows carefully, especially when they show an orange warning.

Is NOVA available in English?

NOVA answers in the language you write in, but its interface is in French for now.

What about Mac or Linux?

Only Windows has an installer for now. Advanced users can run NOVA from its source code on Linux or macOS (see the README on GitHub).

Privacy

NOVA has no server: there's no NOVA account, no usage tracking, no ads. Your conversations, settings and attached files are stored only on your computer, in the %USERPROFILE%\.nova folder.

To work, NOVA contacts some services, only when needed for what you ask:

  • Anthropic (through Claude Code), for the AI itself: your messages, the content of files NOVA reads or that you attach, and the results of its tools. Anthropic's privacy policy applies.
  • DuckDuckGo, when NOVA searches the web: the search terms.
  • The websites NOVA visits for you, such as wttr.in for the weather, with your town's coordinates.
  • OpenStreetMap (Nominatim) and ipinfo.io, when you ask NOVA to detect your location: your coordinates, or your IP address if Windows doesn't know your location.
  • Pollinations, when you ask for an image: the image description.

This site uses no cookies, no analytics and no third-party service: it is hosted by o2switch, in France. Installers are hosted by GitHub.

Code signing policy

NOVA installers are built automatically by GitHub Actions from the repository's public code, and their SHA-256 fingerprint is published with each release. They are not signed yet: NOVA has applied for free code signing by SignPath Foundation (application sent in October 2026). Once accepted, installers will be signed by SignPath Foundation.
