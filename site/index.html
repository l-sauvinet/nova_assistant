Ce que NOVA sait faire

Demande-lui ce que tu veux en français : NOVA choisit le bon outil et le fait pour toi, au lieu de t'expliquer comment le faire.

Tes fichiers

Lire, chercher, ranger, renommer ou résumer tes documents. « Trie mes téléchargements par type », « que dit ce PDF ? ».

Des commandes, avec ton accord

Pour tout le reste, NOVA prépare une commande PowerShell et te la montre. Rien ne s'exécute sans que tu cliques sur « Autoriser ».

Le web et la météo

Recherches sur Internet, lecture de pages, météo de chez toi : NOVA va chercher l'information à jour.

Documents

Un CV, une lettre, une fiche de révision ? NOVA crée de vrais fichiers PDF, Word, HTML ou CSV, avec un aperçu dans la conversation.

Images et visuels

Illustrations, fonds d'écran, logos, schémas ou petites pages interactives, directement dans le chat.

Chez toi, pas dans le cloud

NOVA tourne sur ton PC. Tes conversations sont enregistrées sur ton ordinateur, et NOVA n'a ni serveur, ni compte, ni statistiques d'utilisation.

Tu gardes la main

Un assistant qui agit sur ton ordinateur doit être digne de confiance. NOVA a été conçu pour ne jamais agir dans ton dos.

Il demande avant d'agir

Lancer une commande, supprimer, déplacer ou écraser un fichier, ouvrir un dossier qui n'est pas le sien : NOVA te pose toujours la question d'abord.

Protégé contre les pièges

Une page web ou un fichier peut cacher des instructions destinées à l'IA. NOVA les repère, te prévient, et redemande ton accord pour toute action qui suit.

Fichiers dangereux signalés

Avant d'ouvrir un programme, un script ou un fichier téléchargé, NOVA le fait analyser par Microsoft Defender et t'avertit.

Code ouvert

Tout le code de NOVA est public sur GitHub : n'importe qui peut vérifier ce qu'il fait. Les installeurs sont construits par GitHub à partir de ce code.

Installation

Compte une dizaine de minutes la première fois.

Windows 10 ou 11, 64 bitsAvec une connexion Internet pendant l'installation.
Un abonnement Claude Pro ou MaxNOVA réfléchit grâce à Claude, l'IA d'Anthropic, via Claude Code. Un compte Claude gratuit ne suffit pas.

  1. Télécharger NOVA

    Clique ici ou sur le bouton « Télécharger » en haut de la page : le fichier NOVA-setup.exe se télécharge tout de suite. Si ton navigateur indique que le fichier est rarement téléchargé, choisis « Conserver ».

  2. Lancer l'installeur

    Ouvre le fichier téléchargé. L'installeur n'est pas encore signé, donc Windows affiche « Windows a protégé votre ordinateur » : clique sur Informations complémentaires, puis sur Exécuter quand même.

    C'est normal pour un logiciel récent non signé. Pour vérifier que ton fichier est bien l'original, compare son empreinte SHA-256 avec celle indiquée sur la page de la version (voir la FAQ).

  3. Installer Claude Code

    Ouvre Windows PowerShell depuis le menu Démarrer, colle cette commande officielle d'Anthropic et appuie sur Entrée :

    irm https://claude.ai/install.ps1 | iex

    Ferme PowerShell, rouvre-le, tape claude et connecte-toi avec ton compte Claude dans la page qui s'ouvre.

  4. Ouvrir NOVA

    Lance NOVA depuis le menu Démarrer : il trouve ton compte Claude et c'est parti. Essaie par exemple « Qu'est-ce qu'il y a sur mon bureau ? ».

Questions fréquentes

NOVA est vraiment gratuit ?

Oui : NOVA est gratuit et open source, sous licence MIT. En revanche, l'IA qui le fait réfléchir est celle de ton abonnement Claude (Pro ou Max), payé directement à Anthropic. NOVA ne touche rien dessus.

Pourquoi Windows dit que l'application n'est pas reconnue ?

Parce que l'installeur n'est pas encore signé numériquement : Windows ne connaît pas encore l'éditeur. Une demande de signature gratuite pour projets open source a été envoyée à SignPath Foundation. En attendant, tu peux vérifier que ton fichier est l'original : dans PowerShell, tape Get-FileHash .\NOVA-setup.exe dans ton dossier Téléchargements et compare le résultat avec l'empreinte SHA-256 affichée sur la page de la dernière version.

L'installation de Claude Code affiche « le nom distant n'a pas pu être résolu »

Ton réseau bloque sans doute claude.ai, ce qui est fréquent sur les réseaux d'entreprise ou d'école. Essaie depuis une autre connexion, par exemple ta box personnelle ou le partage de connexion de ton téléphone.

NOVA peut-il faire des bêtises sur mon PC ?

Toute action qui modifie ton ordinateur (commande, suppression, déplacement, écrasement d'un fichier) passe par une fenêtre de confirmation qui montre exactement ce qui va se passer. Tu peux toujours refuser. Lis bien ces fenêtres, surtout quand elles affichent un avertissement orange.

Et sur Mac ou Linux ?

Pour l'instant, seul Windows a un installeur. Les plus à l'aise peuvent lancer NOVA depuis son code source sur Linux ou macOS (voir le README sur GitHub).

Confidentialité

NOVA n'a pas de serveur : il n'y a pas de compte NOVA, pas de statistiques d'utilisation, pas de publicité. Tes conversations, tes réglages et les fichiers que tu joins sont enregistrés uniquement sur ton ordinateur, dans le dossier %USERPROFILE%\.nova.

Pour fonctionner, NOVA contacte certains services, seulement quand c'est nécessaire à ce que tu lui demandes :

  • Anthropic (via Claude Code), pour faire réfléchir l'IA : tes messages, le contenu des fichiers que NOVA lit ou que tu joins, et les résultats de ses outils. C'est la politique de confidentialité d'Anthropic qui s'applique.
  • DuckDuckGo, quand NOVA fait une recherche web : les mots de la recherche.
  • Les sites web que NOVA consulte pour toi, par exemple wttr.in pour la météo, avec les coordonnées de ta ville.
  • OpenStreetMap (Nominatim) et ipinfo.io, quand tu demandes à NOVA de détecter ta position : tes coordonnées, ou ton adresse IP si Windows ne connaît pas ta position.
  • Pollinations, quand tu demandes une image : la description de l'image.

Ce site n'utilise ni cookies, ni outil de statistiques, ni service tiers : il est hébergé par o2switch, en France. Les fichiers d'installation sont hébergés par GitHub.

Code signing policy — Politique de signature du code

Les installeurs de NOVA sont construits automatiquement par GitHub Actions à partir du code public du dépôt, et leur empreinte SHA-256 est publiée avec chaque version. Ils ne sont pas encore signés : NOVA a demandé à bénéficier de la signature gratuite de code de SignPath Foundation (demande envoyée en octobre 2026). Une fois acceptée, les installeurs seront signés par SignPath Foundation.
